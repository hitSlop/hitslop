# Countdown & Milestones

A compact digital departure clock in a capsule body for tracking big events, live countdowns, and key milestones.

- **Job**: Count down to an upcoming date or event with a live ticking vacuum-fluorescent display and check off intermediate milestones along the way.
- **Storage**: Canonical `stores/data.json` storing event title, subtitle, target timestamp, and intermediate milestone checkpoints.
- **Visuals**: Brushed dark titanium capsule bezel (`#2a2c34`), smoked glass window, glowing vacuum-fluorescent golden amber digits (`#f59e0b`), and a tactile milestone track.
