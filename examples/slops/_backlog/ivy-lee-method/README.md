# Ivy Lee Method

A strict six-item single-tasking ledger.

- **Exactly 6 Tasks**: Ranked in strict order of importance from 1 to 6.
- **Single-Task Spotlight**: Focus exclusively on the top incomplete task before moving to the next.
- **Rollover to Tomorrow**: End-of-day action clears finished tasks and shifts incomplete work to tomorrow's docket.

## Development

```sh
bun slop dev examples/slops/ivy-lee-method
bun slop build examples/slops/ivy-lee-method
```
