# 3-3-3 Plan

Oliver Burkeman’s daily finite work docket (*Four Thousand Weeks*).

- **3 Hours of Deep Work**: One core, high-leverage project tracked with 3 hourly milestone blocks or 15-minute steppers.
- **3 Urgent / Shorter Tasks**: Essential friction tasks that must be dealt with today.
- **3 Maintenance Activities**: Routine chores, administrative loops, and self-care required to keep work and life functioning.

## Development

bun slop dev examples/slops/three-three-three
