# Slide Deck

A single-file presentation studio inspired by Bento, featuring structured slide archetypes, live inline canvas editing, and a fullscreen presenter mode.

- **Job**: Compose, preview, and present beautiful slide decks with designer-grade typography and zero layout frustration.
- **Archetypes**: `Title Cover`, `Split 50/50`, `Hero Metric`, `Editorial Quote`, and `3-Card Pillar Grid`.
- **Modes**:
  - **Studio Mode**: Reorderable slide filmstrip, layout switcher, theme selector, inline text editing, and speaker notes.
  - **Presenter Mode**: Fullscreen presentation view, arrow key navigation, progress bar, and speaker notes HUD.
- **Storage**: Canonical `stores/data.json` storing deck title, theme, active slide, and slides array.
- **Themes**: `Swiss Red`, `Obsidian Dark`, `Bauhaus Navy`, and `Archival Linen`.
