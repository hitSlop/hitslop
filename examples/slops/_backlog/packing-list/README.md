# Packing List

A traveler's luggage-tag checklist for hitSlop.

## Features
- Authentic Manila luggage-tag interface with brass eyelet, airmail accents, and barcode strip
- Stamped baggage category codes (`DOCS`, `CARRY`, `TECH`, `TOILET`, `WEAR`, `GEAR`)
- Baggage readiness meter tracking packed items and departure readiness percentage
- Essential item stars (★) and quick item quantity badges (×1, ×2, ...)
- Built-in travel presets (Weekend Getaway, International Flight, Outdoor & Hiking, Business Travel)
- Batch actions: Pack All and Unpack/Reset for the next adventure
- Category and "Remaining only" filtering
- Direct inline editing of trip destination, passenger name, and item details
- Clean static export state for printable packing manifests
- 512×512 icon render target showing an angled baggage tag with brass eyelet and packed rubber seal
