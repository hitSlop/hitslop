# Bullet Journal

Ryder Carroll’s analog rapid logging on cream dot-grid paper.

- **Classic Signifiers**:
  - `•` Task
  - `×` Completed
  - `›` Migrated
  - `‹` Scheduled
  - `○` Event
  - `—` Note
  - `*` Priority mark
- **Interactive Cycle**: Click any signifier symbol to advance through its lifecycle state.
- **Views**: Daily Rapid Log and Monthly Index spread.

## Development

```sh
bun slop dev examples/slops/bullet-journal
bun slop build examples/slops/bullet-journal
```
