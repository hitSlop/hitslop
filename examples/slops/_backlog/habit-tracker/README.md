# Habit Tracker

A cheerful yellow pocket instrument for tracking daily habits, check-ins, streaks, and multi-week consistency.

Features:
- Track multiple habits with custom colors and names
- Chunky, tactile today punch button for instant marking
- Rolling 70-day (10-week) circular check-in bubble matrix
- Current streak, best streak, and 30-day consistency percentage
- Bottom multi-habit quick check bar to mark off the whole day at a glance
- Clean, control-free static export view (`data-slop-export="hide"`)
- Dedicated 512×512 icon render target for Finder and catalog cards

```sh
bun slop dev examples/slops/habit-tracker
bun slop build examples/slops/habit-tracker
```
