# Paused examples

These projects are preserved source, not supported examples. They are excluded
from gallery discovery, active type-checks, tests, and builds. Their dependencies
and relative paths may no longer resolve; do not add compatibility code for them.

Promote one project at a time back to `examples/slops/<slug>`. Follow Quick
Checklist's TypeBox schema/store and theme conventions, then type-check, build,
validate, and smoke-test it before treating it as active. Keep migration changes
separate from this preservation-only move. The init template is also deferred.
