# Wordle

A tactile 5-letter word puzzle instrument for hitSlop.

## Features
- Mechanical letter tiles with tactile flip animations and pop-in typography
- On-screen tactile QWERTY keyboard with dynamic letter feedback
- Physical keyboard support (type A-Z, Enter, Backspace)
- Daily synchronized puzzle and unlimited Practice mode
- Comprehensive player statistics (games played, win percentage, current & max streaks, guess distribution)
- Spoiler-free emoji grid result sharing
- Offline dictionary with curated target words and extended valid guesses
- Export awareness: hides keyboard in static capture and full-page export
- 512×512 icon render target showing embossed word tiles on a dark chassis
