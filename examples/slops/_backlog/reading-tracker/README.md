# Reading Tracker

A vintage library checkout card for logging books, authors, star ratings, and reading status.

- **Job**: Track reading queues, authors, ratings, and finished dates on a tactile manila library checkout card.
- **Storage**: Canonical `stores/data.json` storing member name, since year, book entries (title, author, rating, status, date), and active status filter.
- **Visuals**: Manila card stock (`#f5efe1`), fine ink rules, red library ink stamp (`#b91c1c`), serif header typography, and star rating indicators.
