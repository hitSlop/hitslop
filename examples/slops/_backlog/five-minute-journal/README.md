# Five Minute Journal

A mindful morning-and-evening bookend journal.

- **Inspiring Thought**: Daily quote to anchor the day.
- **Morning (AM)**:
  1. Three gratitudes (specific scenes and sensory joys).
  2. Three intentions ("What would make today great?").
  3. Daily affirmation ("I am...").
- **Evening (PM)**:
  1. Three amazing things that happened today.
  2. One reflective lesson or growth point.
- **View Toggles**: Switch between Full Day, Morning only, or Evening only.
