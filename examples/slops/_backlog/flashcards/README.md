# Flashcards

A tactile index-card study machine with 3D card flips, deck editing, and Leitner spaced repetition.

Features:
- Ivory catalog card with a red margin rule and brass drawer label
- Flip with click or Space; grade with 1 (again) and 2 (good)
- Leitner boxes: New, Review, Known, Mastered
- Add, edit, shuffle, and remove cards; create extra decks
- Clean static export (`data-slop-export="hide"`)
- Dedicated 512×512 icon render target

```sh
bun slop dev examples/slops/flashcards
bun slop build examples/slops/flashcards
```
