# Pocket Spreadsheet

A tactile, lightweight spreadsheet with formula evaluation, cell ranges, multi-cell selection, and CSV export.

- **Job**: Fast financial modeling, quarterly estimates, tabular logs, and formula calculations without cloud bloat.
- **Formula Engine**: In-house 100% MIT calculation engine supporting arithmetic (`+ - * / ^`), `=SUM()`, `=AVG()`, `=MIN()`, `=MAX()`, `=COUNT()`, `=ROUND()`, `=IF()`, cell references (`A1`, `B2`), ranges (`A1:B5`), and visual widgets (`=PROGRESS()`, `=TAG()`, `=RATING()`).
- **Storage**: Canonical `stores/data.json` storing title, grid dimensions, and sparse cell data/formulas.
- **Aesthetic**: Vintage green-bar ledger stock (`#f4f8f3`), dark graphite workstation chassis (`#1a1d22`), formula bar (`fx`), and emerald selection box.
