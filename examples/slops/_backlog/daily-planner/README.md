# Daily Planner

A folded appointment book for a single day. Three tickable priorities sit above a ruled
6am–midnight hour rail, and a vermilion marker tracks the current time. Hours already spent
fade back so the remaining day is what reads.

The rail is the ruler: drag down empty paper to draw a block, drag its left bar to move it,
and drag the handles at either edge to stretch it. Everything snaps to a quarter hour. Each
kind — focus, meeting, break, personal — is a different ink, distinguished by hue and by the
pattern of its bar. Arrow keys nudge whichever handle has focus.

```sh
bun slop dev examples/slops/daily-planner
bun slop build examples/slops/daily-planner
```
