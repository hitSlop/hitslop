# Grocery List

A playful fridge-magnet shopping pad for organizing and checking grocery essentials by aisle.

- **Job**: Rapidly jot down and check off grocery items by aisle/section, keeping sticky reminder notes attached to an enamel fridge door.
- **Storage**: Canonical `stores/data.json` storing items (name, section, done), sticky note text, and selected filter.
- **Visuals**: Enamel refrigerator surface (`#e7e3d8`), ruled paper pad (`#fffef9`), colorful tactile 3D magnets (banana, smiley, strawberry, star), and a soft pink pinned sticky memo.
