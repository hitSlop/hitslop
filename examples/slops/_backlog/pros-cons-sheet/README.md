# Decision Balance

Benjamin Franklin’s "prudential algebra" on folded stationery.

- **Whether to...**: Clear decision headline statement.
- **Two Columns**: Motives for (Pros) and against (Cons).
- **Point Weights**: Rate each argument from 1 (minor factor) to 5 (vital decisive factor).
- **Prudential Balance Gauge**: Live scale tipping left or right with point totals and net delta.
- **Verdict & Synthesis**: Status stamp (Evaluating, Leaning Pro, Leaning Con, Decided) with resolution notes.
