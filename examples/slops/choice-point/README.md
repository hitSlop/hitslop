# Choice Point

A quiet ACT worksheet based on Dr. Russ Harris’s fork-in-the-road diagram: name the moment, map away versus towards, pause with STOP, and pick one tiny move.

From the repository root:

```sh
bun slop dev examples/slops/choice-point
bun slop build examples/slops/choice-point
bun slop register examples/slops/choice-point
```

Create a writable copy of the registered template before editing.
