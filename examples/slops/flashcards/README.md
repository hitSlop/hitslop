# Flashcards

An electric-blue study deck with flipping cards, answer-first grading, editable
decks, and four learning stages.

```sh
bun run slops:review flashcards
bun slop build examples/slops/flashcards
bun slop validate examples/slops/flashcards/dist/flashcards.slop
```

Reveal with Space or the card. After revealing, use 1 for Again or 2 for Got it.
Editing and shuffle remain available at narrow widths.
