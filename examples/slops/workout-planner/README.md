# Workout Planner

A Game Boy-inspired training cartridge with exercises, sets, reps, and completion tracking.

- **Job**: Track workout routines (exercises, target sets/reps, weights, completion) with a retro handheld feel and quick rest timer.
- **Storage**: Canonical `stores/data.json` storing workout title, date/tag, exercise items (sets target, completed sets, weight), and timer preset.
- **Visuals**: Molded atomic purple cartridge casing (`#453164`), speaker grille slots, green LCD matrix screen (`#9cb796`), and a dumbbell badge insignia.
