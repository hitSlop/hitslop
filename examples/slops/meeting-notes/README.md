# Meeting Notes

A sober green meeting memo for capturing agenda topics, live notes, key decisions, and assigned actions.

- **Job**: Capture meeting flow from preparation to followup in a single document that exports cleanly without control clutter.
- **Storage**: Canonical `stores/data.json` storing meeting title, date, location/link, attendees, agenda items, markdown-style freeform notes, explicit decisions, and checkable action items with owners.
- **Visuals**: Sober forest/olive green memo casing (`#23382c`), warm cream paper sheet (`#f8f6f0`), dark forest ink typography, and acid-lime callout accents (`#b5cc28`).
