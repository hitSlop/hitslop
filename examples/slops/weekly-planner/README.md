# Weekly Planner

A ruled cream desk planner for scheduling days, time-blocking, and keeping weekly focus in view.

- **Job**: Map out appointments, projects, and top tasks across the week with a desktop blotter feel.
- **Storage**: Canonical `stores/data.json` storing week date range, main weekly focus, and day column tasks.
- **Visuals**: Ruled warm cream stock (`#faf7ee`), fine red ledger rules, dark navy ink typography (`#1e293b`), and checkable rank boxes.
