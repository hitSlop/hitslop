# Magnetic week board

Single job: arrange your week by giving tasks space in time.

An Instrument with a white scheduling surface, ink-blue header, recessed hour
lanes, and raised sky/coral/mint/lilac magnets. Color is personal organization,
not an inferred category. Completion also uses a checkmark. Bold Avenir day
numbers and precise hour markings keep the grid easy to scan.

The window is the board boundary. At 880 × 560 all seven days fit; narrow windows
scroll the same board horizontally. Day headings and the hour ruler remain
visible. The full day is available, opening at 8am. Anytime tasks sit above it.

Draw to draft, drag to move, pull edges to resize. Preview gestures locally and
commit on release; Escape cancels. A Bits UI dialog provides explicit editing,
including day and time changes without dragging. Arrow keys move a selected
block between days or in 15-minute steps; resize handles use up/down arrows.

Older task time strings and unknown fields survive. Missing durations display
as one hour; invalid times remain visible in Anytime. Exports use complete,
readable day lists rather than clipping the live scroll viewport. The icon is
a miniature magnetic board, with a check only when all blocks are complete.
