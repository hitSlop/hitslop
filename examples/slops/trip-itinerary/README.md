# Trip Itinerary

A lilac transit boarding pass for organizing days, flights, hotels, stops, and a packing stub.

Features:
- Route badges, flight / gate / seat tags, and a perforated coupon stub
- Multi-day timeline with direct-edit times, titles, and places
- Checkable packing list on the boarding stub
- Clean static export for a travel document (`data-slop-export="hide"`)
- Dedicated 512×512 icon render target

```sh
bun slop dev examples/slops/trip-itinerary
bun slop build examples/slops/trip-itinerary
```
