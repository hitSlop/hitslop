# Trip Itinerary

A lilac boarding-pass booklet for a chronological trip: day tabs, flight and hotel stubs, and a perforated packing coupon.

```sh
bun slop dev examples/slops/trip-itinerary
bun slop build examples/slops/trip-itinerary
bun slop validate examples/slops/trip-itinerary/dist/trip-itinerary.slop
```
