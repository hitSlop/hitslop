# Water Tracker

A translucent aqua hydration instrument with a live liquid-level readout and quick-tap logging.

- **Job**: Track daily water intake against a target goal, logging glasses and bottles with satisfying liquid animations.
- **Storage**: Canonical `stores/data.json` storing daily target, current intake, unit (`ml` or `oz`), and today's drink history logs.
- **Visuals**: Translucent frosted aqua shell (`#083344`), deep ocean teal flask chamber, gently oscillating liquid wave surface, and cyan level indicators.
