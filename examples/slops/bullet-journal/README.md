# Bullet Journal

Ryder Carroll’s analog rapid logging on cream dot-grid paper.

- **Classic signifiers**: `•` Task · `×` Completed · `›` Migrated · `‹` Scheduled · `○` Event · `—` Note · `*` Priority
- **Rapid log**: click a bullet to cycle its signifier; star a line for priority
- **Spreads**: Daily Rapid Log and Monthly Index

```sh
bun slop dev examples/slops/bullet-journal
bun slop build examples/slops/bullet-journal
bun slop validate examples/slops/bullet-journal/dist/bullet-journal.slop
```
