# Ambient Mixer prototype

An isolated authored-skin experiment for hitSlop. It intentionally does not appear in the bundled template picker and does not produce audio; the prototype tests visual direction, Bits UI interactions, persistence, and app-owned light/dark palettes.

Build from the repository root:

```sh
node sdk/bin/slop.mjs build "Prototypes/Ambient Mixer.slop"
```

Evaluate the default authored appearance only. Applying a catalog theme is outside this experiment.
