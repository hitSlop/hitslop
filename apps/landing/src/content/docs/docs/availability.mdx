---
title: Availability
---

Available: macOS 14+ on Apple silicon, bundled and local templates, recents, native document editing, and PNG/PDF export.

Coming soon: [live collaboration](/docs/guides/live-sharing/). The website preview uses simulated participants.

Future work: hosted catalog, hosted template publishing, media import, iCloud and other synced folders, iOS, Windows, undo UI, and schema evolution. No migration from pre-v1 packages is supported.
