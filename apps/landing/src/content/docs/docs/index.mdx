title: hitSlop documentation
---

hitSlop is a local macOS host for small apps and documents. Start with Quick Checklist or Small Expenses, create a writable copy, and keep your work on your Mac. PNG/PDF export and agent editing are supported.

Start with [create your first slop](./getting-started/) to build an app, or [document editing](./guides/edit-installed-data/) to work with an existing document. For terminal tasks, see [CLI workflows](./guides/cli-workflows/). [Availability](./availability/) covers supported platforms and planned features.
